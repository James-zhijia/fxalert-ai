AI 輔助開發使用心得

使用工具:ChatGPT

使用方式與實際經驗

這次開發 FXAlert AI 時，我有使用 ChatGPT 協助規劃專案功能、了解 FastAPI 的使用方式，以及討論程式的實作邏輯。

在開發過程中，也遇到一些問題。例如，當時使用 POST API 新增匯率提醒後，發現 GET API 沒有顯示預期的資料，一開始以為是 SQLite 沒有成功儲存。

後來透過 AI 協助排查，學習如何使用 Python 直接檢查 SQLite 資料庫，確認資料筆數、資料庫路徑，以及 API 是否讀取到正確的資料。經過重新測試，也確認資料在重新啟動 FastAPI 後仍然能正常保留。

另外，在實作匯率提醒功能時，我也透過 AI 協助理解如何判斷匯率是否達標，以及如何避免持續達標時重複觸發，最後再使用 Swagger UI 和 Pytest 進行測試。

使用心得

我覺得 AI 對我最大的幫助，是當遇到不熟悉的技術或程式錯誤時，可以提供排查方向，讓我知道應該從哪裡開始檢查，而不是一直盲目修改程式。

不過我也發現，AI 提供的建議不一定就是問題的真正原因，還是需要自己實際執行、查看錯誤訊息，才能確認。

透過這次專案，我不只學習到 FastAPI、SQLite 和 GitHub Actions 的基本應用，也更了解如何利用 AI 輔助開發，同時培養自己分析問題與驗證結果的能力。
